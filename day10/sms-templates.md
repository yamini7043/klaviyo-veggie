Farm2Home SMS Templates

1. Post-Purchase SMS

Flow: Placed Order → Order Confirmation Email → SMS (if SMS consent = true)

Message

Hi {{ first_name }}, your Farm2Home order is confirmed! 🚚 Fresh delivery expected on {{ delivery_date }}. Track your order: {{ tracking_link }}. Reply STOP to opt out.

2. Flash Sale SMS Template

Purpose:Promotional campaigns

Message

Fresh deal for you, {{ first_name }}! 🥭 {{ item }} at {{ discount }} OFF — today only. Shop now: {{ link }}. Reply STOP to opt out.

Example

Fresh deal for you, Priya! 🥭 Mangoes at 20% OFF — today only. Shop now: farm2home.com/mangoes. Reply STOP to opt out.

3. Restock Alert SMS Template

Purpose: Notify customers when a popular item returns

Message

{{ first_name }}, the {{ item }} you viewed is back in stock! 🌱 Grab it before it sells out: {{ link }}

Example

Priya, the Alphonso Mangoes you viewed are back in stock! 🌱 Grab them before they sell out: farm2home.com/mangoes

4. Delivery Out for Delivery SMS

Message

Good news, {{ first_name }}! 🚚 Your Farm2Home order is out for delivery and will arrive shortly. Track here: {{ tracking_link }}
