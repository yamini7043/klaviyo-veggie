# A/B Test Plan – Restock Email CTA

### Flow

Post-Order Veggie Flow

### Email Tested

Running Low, {{ first_name }}? Time to Restock

### What Are You Testing?

The CTA button text in the Restock Email.

### Version A (Control)

CTA Button:
Reorder Now

### Version B (Variation)

CTA Button:
Restock My Kitchen

### Hypothesis

A more personalized CTA ("Restock My Kitchen") will increase click rate by at least 5% compared to the generic CTA ("Reorder Now").

### Split

50% Version A

50% Version B

### Winning Metric

Click Rate

### Secondary Metrics

* Placed Order Rate
* Revenue Per Recipient

### Test Duration

Run the test until each version receives at least 100 sends.

Expected duration: 1–2 weeks depending on flow volume.

### Success Criteria

The winning version will:

* Generate the highest click rate.
* Maintain or improve placed order rate.
* Drive more repeat purchases.
